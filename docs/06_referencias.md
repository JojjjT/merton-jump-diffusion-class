4. **Metaanálisis de cambio conceptual (218 estudios, N=18.051).** g = 1.10.

## Notas de uso

- Estas referencias sostienen el marco pedagógico de la clase.
- Para una discusión técnica completa del proceso de salto, consultar Merton (1976).
- Para la conexión entre regulación metacognitiva y transferencia lejana, consultar Wirth et al. (2025) y Gobet & Sala (2023).
- El modelo de debriefing 3D se aplica para convertir la simulación en una intervención cognitiva.
